A tiny program that writes one absurd clause buried deep in a terms-of-service agreement — deadpan legal boilerplate about a toaster that judges your bread and claims your crumbs.

## Run it

```sh
node main.ts
```

It writes exactly one line (137 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run.
